# Dependencies and model provenance

This project contains original model/training/inference code and weights trained from random initialization on locally generated fixtures. No third-party model weights are included.

Development dependencies: NumPy (BSD-3-Clause), Pillow (MIT-CMU/HPND), and optional PyTorch (BSD-style). Consult the installed packages for their exact license texts. Python, GCC, Linux images, CUDA, and Arduino platform components have their own licenses; this project's MIT license does not replace them.

The source model is not pretrained and the synthetic fixture dataset is not real desktop training data. The included weights do not establish task-language understanding or general desktop accuracy.
